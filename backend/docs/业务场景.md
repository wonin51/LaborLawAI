# 劳动合同法律助手业务场景提取

## 用户咨询场景

1. 劳动合同签订咨询：劳动者或应届毕业生询问劳动合同签订、未签合同、三方协议、试用期约定等问题。
2. 工资与加班争议咨询：用户咨询工资拖欠、加班工资、工资支付周期、休息休假和考勤证据留存。
3. 解除/终止合同咨询：用户咨询试用期辞退、无理由解除、违法解除、离职后工资结算和经济补偿。
4. 社保与公积金咨询：用户咨询入职后社保缴纳、断缴、补缴、实习生或应届生相关保障问题。
5. 劳动仲裁与维权路径咨询：用户需要了解协商、投诉举报、劳动仲裁、诉讼等处理路径和材料准备。
6. 证据准备咨询：系统围绕劳动合同、工资流水、考勤记录、聊天记录、加班通知、工作成果、社保缴纳记录等给出清单。
7. 合同条款审查：用户粘贴试用期、工资工时、解除终止、保密竞业等条款，系统识别明显风险并给出修改建议。
8. 超范围或高风险问题处理：用户要求预测仲裁胜诉、提出非劳动合同领域问题或依据不足时，系统应安全拒答并提示咨询专业机构。

## 管理后台场景

1. 知识库入库：管理员上传法律法规、司法解释、人社政策、FAQ或示例合同，系统解析、切分并生成向量索引。
2. 来源与版本管理：管理员维护标题、来源URL、发布日期、适用范围、版本号和启停用状态。
3. 高频问答维护：管理员补充和优化加班、试用期、未签合同、工资拖欠等高频问题的标准问答。
4. 问答反馈处理：管理员查看用户点赞、点踩和错误反馈，定位低质量回答并优化知识库或提示词。
5. 合规与安全管理：系统提示用户脱敏，日志避免明文保留身份证号、手机号等敏感信息。

## 演示验收场景

1. 典型问题问答演示：围绕加班工资、未签合同、试用期辞退、竞业限制条款和胜诉承诺拒答进行端到端演示。
2. 引用溯源演示：展示答案中的法规名称、条款或政策标题，并支持展开依据片段。
3. 管理后台演示：展示文件入库、启停用、反馈查看和FAQ维护。
4. 质量指标验收：验证常见问题命中率、引用覆盖率、回答结构完整性、响应时间和安全拒答效果。
